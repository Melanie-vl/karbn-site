# Karbn website prototype

Statische prototype (HTML, CSS, JavaScript). Geen build nodig.

## Zo zet je hem op GitHub Pages
1. Maak op github.com een nieuwe repository, bijvoorbeeld `karbn-site` (openbaar).
2. Klik "uploading an existing file" en sleep de inhoud van deze map erin
   (index.html, de map img, karbn-draai.mp4, karbn-poster.jpg, .nojekyll). Commit.
3. Ga naar Settings > Pages. Kies bij Source "Deploy from a branch",
   branch `main`, map `/ (root)`. Opslaan.
4. Na 1 tot 2 minuten staat de site op https://JOUWNAAM.github.io/karbn-site/

## Aanpassen
- Teksten en opmaak staan in index.html.
- Foto's vervang je in de map img (zelfde bestandsnaam houden).
- De video vervang je door een eigen karbn-draai.mp4 (zonder geluid, 8 tot 12 seconden).
- Gele invulplekken (prijs, Why-tekst, team, e-mail, datum) moeten nog worden ingevuld.

Let op: dit is een prototype. De echte webshop komt op Leenweb/WordPress.
